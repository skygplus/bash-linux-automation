# Bash Linux Automation Project

## Overview

This project demonstrates beginner Bash scripting and Linux automation techniques.

The project covers:

- Directory and file automation
- Dynamic file generation
- System health monitoring
- Functions
- External function libraries
- Input validation
- Error handling
- Exit codes
- Signal handling
- Cleanup using trap
- Git and GitHub workflow

## Technology Stack

- Ubuntu Linux
- Bash
- Git
- GitHub
- VS Code
- WSL2
